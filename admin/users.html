📖 Panduan Mengelola User (Via Supabase)

1. Menambah User Baru (Juri/Panitia/Kontingen)

Buka Supabase -> Authentication -> Users -> Klik "Add User" -> Isi Email (contoh: juri2@jumbara.local) dan Password -> Centang "Auto Confirm User".

2. Mengubah Role User

Buka Supabase -> SQL Editor -> Jalankan perintah:

update auth.users set raw_app_meta_data = raw_app_meta_data || '{"role": "juri"}'::jsonb where email = 'juri2@jumbara.local';

*(Ganti "juri" dengan role yang diinginkan: super_admin, koordinator, admin_event, juri, kontingen).*

3. Mereset Password User

Buka Supabase -> Authentication -> Users -> Cari user -> Klik titik tiga (...) -> Pilih "Reset Password" atau "Send Recovery".
